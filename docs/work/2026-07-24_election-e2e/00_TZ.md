# ТЗ — E2E-спек для election (real suite)

Дата: 2026-07-24
Ветка: `feat/election-e2e` (создаёт ревьюер от main)
Исполнитель: кодер в tmux astro2. Коммитит ревьюер.

## Контекст

Для election нет e2e — из-за этого пропустили 3 бага (eventType, quota-commit, LLM-метод). Интеграционные pytest уже есть (`apps/api/tests/test_election_*`). Нужен настоящий e2e в release-сьюте: браузер → реальный API → реальный sidecar → реальный LLM.

Образец — `e2e/readings-horary.spec.ts` (читай целиком) и `e2e/fixtures.ts` (`completeOnboarding`, `grantReferralAccess` — реальный 14-дневный доступ через настоящий реферальный клейм → weekly-free кредит). Election делит кошелёк с хораром, тот же механизм доступа подходит.

## Что создать

`e2e/readings-election.spec.ts` — по структуре horary-спека (AI_HEADER/контракты по AGENTS.md):

1. **lists election card**: после onboarding + `grantReferralAccess` → `/readings` → `getByTestId("readings-card-election")` visible.
2. **real election lifecycle** (главный сценарий):
   - Клик по карточке → `election-screen` `data-state="ready"`, `data-access-state="unlocked"`.
   - Выбор категории `election-category-card-relations` → подкатегории visible → клик по чипу «Свидание» → поле «Свой запрос» заполнилось.
   - Окно — дефолт (2 недели). Submit (кнопка «Подобрать даты»).
   - Processing виден (шаги или spinner), затем poll до результата: `election-result-view` visible (timeout 120s — реальный LLM).
   - Assert: `election-hero` visible; внутри hero — бейдж («Отличный день» или «Хороший день»); блок narrative — раскрыть «Почему этот день?» и проверить, что тексты непустые (hero_reason в hero, после раскрытия — «Астрологически» и «Простыми словами» видны).
   - `election-calendar` visible; есть хотя бы один день с классом best/good (проверить через `election-calendar-day-*` count > 0 у marked дней — реализуй поиск по атрибуту/class, не хардкодь даты).
   - Секция «Лучше не начинать» или её отсутствие — оба валидны (не падать, если avoid_days пуст).
3. **quota decreased**: после done — вернуться на `election-screen` (кнопка «Новый подбор») → quota-bar показывает на 1 меньше (weekly-free был 1 → 0) ИЛИ locked. Прочитать текст quota-бара и проверить.

## Требования к реализации

- Без моков и route interception — только реальный стек, как horary-спек.
- НЕ хардкодить конкретные даты/тексты LLM (LLM недетерминирован): проверять структуру, видимость, непустоту и классы, не точные строки.
- Один поиск на спек (LLM-расход минимальный), окно — дефолтные 2 недели.
- data-testid — только из ТЗ выше; если какого-то testid в компонентах нет — НЕ добавлять в код, спроси ревьюера (список смотри в components/readings/election/election-result-view.tsx и election-form.tsx).
