### 2. Secondary progression model

Use the standard symbolic day-for-year model:

```text
age_years = (target_jd - birth_jd) / 365.2425
progressed_jd = birth_jd + age_years
```

Then calculate progressed positions at `progressed_jd` with existing Swiss Ephemeris helpers.

Minimum supported W3.5 output:

- Progressed Moon aspects to natal planets;
- Progressed Moon aspects to natal angles;
- Progressed Moon aspects to natal lots;
- Progressed Sun sign transition;
- Progressed Sun natal-house transition.

For progressed Sun transitions:

- do not emit a generic always-on "Sun is in sign/house" activation;
- emit only when progressed Sun is within configured transition orb of a sign boundary or natal house cusp;
- use the same progression orb unless a separate canon key is added;
- include debug fields showing boundary/cusp longitude and distance.

### 3. Solar arc model

Compute solar arc delta from progressed Sun:

```text
solar_arc_delta = normalize(progressed_sun_longitude - natal_sun_longitude)
```

Apply delta to natal longitudes:

```text
solar_arc_longitude(point) = normalize(natal_longitude(point) + solar_arc_delta)
```

Minimum supported W3.5 output:

- Solar Arc planets to natal angles;
- Solar Arc planets to natal personal planets;
- Solar Arc planets to natal lots if within orb.

Personal planet targets:

```text
SUN, MOON, MERCURY, VENUS, MARS
```

Source planets may use all currently supported sidecar planets, but ordering must be deterministic and stable.

### 4. Aspect detection

Use existing canonical aspect map from `activation_builder.py`:

```text
conjunction, semi_sextile, semi_square, sextile, square,
trine, sesqui_quadrate, quincunx, opposition
```

Use progression max orb from canon:

```yaml
techniques:
  solar_arc:
    orb: 1.0
  secondary_progression:
    orb: 1.0
```

If these keys are missing or non-numeric, fail loudly in tests/dev. Do not hardcode hidden fallback orbs.

When multiple aspects are within orb for the same source/target pair, choose the closest aspect by orb.

Strength:

- add explicit `progression_base` keys under `activation_strength`;
- strict lookup, no default fallback;
- combine base with orb factor deterministically:

```text
orb_factor = max(0, 1 - orb / max_orb)
strength = round(min(1.0, base_strength * orb_factor), 4)
```

Recommended canon keys:

```yaml
activation_strength:
  progression_base:
    solar_arc_aspect: 0.70
    progressed_moon_aspect: 0.65
    progressed_sun_sign_transition: 0.50
    progressed_sun_house_transition: 0.50
```

Polarity must come from aspect classification for aspect activations. Sun transition activations are `neutral`.

### Solar arc activations

Kinds:

```text
solar_arc_aspect
```

Stable IDs:

```text
solar_arc__<SOURCE_PLANET>__<ASPECT_UPPER>__NATAL_<TARGET_PLANET>
solar_arc__<SOURCE_PLANET>__<ASPECT_UPPER>__NATAL_ANGLE_<ANGLE>
solar_arc__<SOURCE_PLANET>__<ASPECT_UPPER>__NATAL_LOT_<LOT>
```

Frames:

```text
source_frame = solar_arc
target_frame = natal | angle | lot
```

Evidence examples:

```text
Solar Arc Mars square natal Venus, orb 0.42°
Solar Arc Jupiter conjunct natal MC, orb 0.31°
Solar Arc Moon trine lot Fortune, orb 0.64°
```

Indexes:

- planet targets -> `by_planet[target_key]`;
- angle targets -> `by_angle[angle]`;
- lot targets -> `by_lot[lot]`;
- no unrelated index writes.

### Secondary progression activations

Kinds:

```text
progressed_moon_aspect
progressed_sun_sign_transition
progressed_sun_house_transition
```

Stable IDs:

```text
secondary_progression__MOON__<ASPECT_UPPER>__NATAL_<TARGET_PLANET>
secondary_progression__MOON__<ASPECT_UPPER>__NATAL_ANGLE_<ANGLE>
secondary_progression__MOON__<ASPECT_UPPER>__NATAL_LOT_<LOT>
secondary_progression__SUN_SIGN_TRANSITION__<SIGN>
secondary_progression__SUN_HOUSE_TRANSITION__<N>
```

Frames:

```text
source_frame = progressed
target_frame = natal | angle | lot
```

Evidence examples:

```text
Progressed Moon square natal Mercury, orb 0.72°
Progressed Moon trine natal ASC, orb 0.44°
Progressed Sun near Leo sign transition, distance 0.38°
Progressed Sun near natal house 9 cusp, distance 0.29°
```

Indexes:

- planet targets -> `by_planet[target_key]`;
- angle targets -> `by_angle[angle]`;
- lot targets -> `by_lot[lot]`;
- Sun sign transition -> `by_planet["SUN"]`;
- Sun house transition -> `by_house[str(house)]`.
