# Дизайн election v2 (подбор даты) — зафиксированные решения и бэклог

Дата: 2026-07-24
Прототип (одобрен поэтапно): https://dev.astro.vasiliy-ivanov.ru/election-proto.html (`public/election-proto.html`, в git НЕ коммитим пока)

## Утверждённая структура

- **6 базовых категорий** с контекстными подкатегориями:
  - Отношения (свидание/свадьба/примирение), Работа и дела (новая работа/запуск/документы), Поездки (путешествие/деловая/к родным), Покупки и финансы (покупка/вложения), Красота и тело (салон/процедуры), Семья и дом (зачатие/переезд)
  - «Свой запрос» — свободный текст (как в боевом интерфейсе)
  - Здоровье: пока подтема в «теле»; при развитии — отдельная базовая (правило «Луна НЕ в знаке органа»)
- **Результат**: hero-карточка лучшего дня (дата, бейдж, причина, лучшее время из VOC, раскрывашка), ещё дни, лента avoid
- **Контент-модель «мяса»** (утверждено):
  - «Почему именно для тебя» — связка с натальной картой (натальная Луна юзера из профиля)
  - «По-человечески» — расшифровка терминов простым языком (Луна = фон дня, управитель знака, что это значит)
  - Каждый хороший день — своё описание
  - Плохие дни — доказательства со временем (VOC-окна, точные аспекты) + практическое следствие

## Бэклог (после порта в React)

1. **Бэк-обогащение**: матрица текстов событие×знак в канон (`election_rules`), personal натальная связка, лучшие часы из VOC-интервалов, доказательства avoid из engine facts, LLM narrative на hero (фаза 4).

2. **Календарный вид результата** (идея владельца 2026-07-24): когда дней в окне много — показывать календарь-месяц с маркировкой хороших/нейтральных/плохих дней (зелёный/серый/красный) вместо только топ-3. Переиспользовать визуальный паттерн `components/calendar/` (там уже есть day-status). Решить: календарь как альтернативный вид результата или основной при окне > 14 дней.

3. **Бот-напоминание о дне события** (идея владельца 2026-07-24): за день до лучшего (или плохого) дня из сохранённого подбора — сообщение в бота: «Завтра, 16 августа — отличный день для «свидание» ✨» + кнопка «Открыть разбор». Механика:
   - Джоб по образцу `feedback_broadcast` (outbound клиент и таймер уже есть)
   - Deep link в отчёт: `t.me/AstroGrace_Bot/app?startapp=election_<id>` — фронт роутит по start_param на `/readings/election/<id>` (различать префикс `election_` от реферального tg-id в auth hook)
   - Выборка: юзеры с done-подбором, у которых завтра (локальная таймзона) есть best day; анти-спам: не чаще 1 раза в день, opt-out в профиле (флаг позже)

## Открытые вопросы

- Здоровье: отдельная базовая категория с правилом «Луна НЕ в знаке оперируемого органа» (обследование/лечение/операции) — решить при расширении.
- Матрица текстов: писать в канон yml шаблонами или LLM генерит по фактам (граница: факты — engine, слова — LLM).
