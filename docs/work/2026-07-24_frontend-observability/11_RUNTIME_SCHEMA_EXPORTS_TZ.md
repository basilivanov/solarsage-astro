# Slice 11 — stable runtime schema exports

## Цель

Открыть через handwritten runtime barrel уже сгенерированные авторитетные схемы,
нужные следующим маленьким API instrumentation-срезам.

## Разрешённые файлы

- `packages/contracts/runtime.ts`
- `__tests__/contracts/generated-runtime.test.ts`

## Требования

1. Импортировать из `./_generated.zod` и экспортировать под стабильными именами:
   - `AccessSummaryWireSchema` -> generated `AccessSummary`;
   - `CalendarPayloadWireSchema` -> generated `CalendarPayload`;
   - `ProfileReadWireSchema` -> generated `ProfileRead`.
2. Не менять autogenerated `_generated.zod.ts` и source contracts.
3. Существующие runtime exports/имена не менять.
4. Обновить GRACE module contract/map у `runtime.ts`: outputs/public
   entrypoints должны перечислять новые stable exports.
5. В тесте добавить компактные canonical valid fixtures и проверить для каждой
   новой схемы: valid fixture принимается, `{}` отвергается. Не тащить PII и не
   ослаблять схему.

## Проверка

```bash
npx vitest run __tests__/contracts/generated-runtime.test.ts && npx tsc --noEmit
```

Другие файлы не менять. Ничего не коммить и не пушить — коммит делает ревьюер.
