## Цель

Документация проекта должна быть однозначной и не путать: синхронизировать grace-канон артефакты, верификационную матрицу, knowledge graph и продуктовые docs с текущим кодом; убрать решения, которые уже изменены; кодеру оставить удобную навигацию (контракты, блоки, owned_tests там, где их не хватает).

## Срезы

### Slice 0 — Canon/tooling (архитектор сам, без кодера)

- coder-loop SKILL.md: гайд архитектора «Постановка ТЗ по GRACE canon §10.7» (11 элементов packet + reviewer-правило неполноты).
- AGENTS.md: owned_tests обязателен в MODULE_MAP; указание что GRACE_CANON.md — policy baseline, AGENTS.md — operative canon.
- Этот мастер-план закоммитить.

### Slice 1 — Research (кодер, read-only)

Аудит расхождений docs ↔ код. Отчёт в `docs/work/2026-07-25_docs-sync/01_AUDIT_REPORT.md`:

- `docs/*.md` верхнего уровня (00_…21_, RUNBOOKS): какие решения/порты/flows противоречат текущему коду (USE_FIXTURES удалён, Prefect удалён, auth path, promo, error loop, deploy path, sidecar).
- `grace/`: canon.yaml, knowledge-graph.xml, IMPLEMENTATION_STATUS.md, README.md, ROLES.md, development-plan*, requirements.xml, technology.xml, frontend.paths — что устарело относительно main.
- Список «устарело, но исторически ценно» vs «активно врёт — править/удалять».

### Slice 2 — grace/ sync (кодер, по отчёту Slice 1)

Привести grace-артефакты к текущему состоянию: knowledge-graph (добавить promo/error-loop модули, убрать удалённое), IMPLEMENTATION_STATUS, canon.yaml/technology.xml при расхождениях. verification-matrix уже синхронизирована (UC-PROMO-REDEEM).

### Slice 3 — docs/ sync (кодер, по отчёту Slice 1)

Точечные правки верхнеуровневых docs: актуальные порты/auth/deploy/error loop; явная пометка superseded для исторических ТЗ (banner «исторический документ, не отражает текущее поведение») вместо переписывания.

### Slice 4 — Markers backfill (кодер)

Приоритетные файлы без MODULE_MAP / START_BLOCK / owned_tests: топ по размеру и активности (app/(grace) страницы, components/*, крупные lib/*, apps/api/app/services/*). Тривиальные файлы не трогать. Каждая итерация ≤ 5 файлов.

### Slice 5 — Final gate (архитектор)

- `bash scripts/grace/check-markers.sh`
- `python3 scripts/check_logging_guardrails.py`
- vitest + pytest (CI-режим)
- Отчёт пользователю.

## Критерии приёмки контура

1. Ни один активный документ не противоречит коду main; исторические ТЗ помечены superseded.
2. `grace/` артефакты перечисляют promo + prod-error-loop модули и не перечисляют удалённое (Prefect/USE_FIXTURES).
3. SKILL.md содержит 11-элементный packet-гайд; AGENTS.md требует owned_tests.
4. Backfill: все приоритетные файлы из Slice 4 имеют MODULE_MAP/блоки/owned_tests; lint чистый.
