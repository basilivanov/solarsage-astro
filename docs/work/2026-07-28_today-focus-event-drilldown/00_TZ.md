# Master TZ — Focus Event Drilldown (модалка события «Что сошлось»)

Дата: 2026-07-28
Волна: W5-FOCUS-EVENT-DRILLDOWN (продолжение программы «День», после W4)
Статус: master-план; кодеру выдаются только локальные срезы 01/02.

## Цель (наблюдаемый результат)

На экране дня в блоке «Сошлось сегодня» / «События дня» каждое событие
(«Луна в напряжении с твоим Плутоном» и т.п.) становится кликабельным.
По клику открывается премиальная bottom-sheet модалка с объяснением:
что это за контакт, что за что отвечает (функции планет), как работает
аспект, и точные цифры (орб в градусах/минутах, точное время, фаза,
окно действия, сила, полюс). Данные подгружаются ЛЕНИВО — отдельным
запросом при открытии модалки, основной payload дня не растёт.

## Эталон UX

Синастрийный дрилдаун аспекта (`components/synastry/aspect-drilldown-sheet.tsx`,
endpoint `/api/synastry/{partner_id}/aspect/{aspect_id}`) — та же идея:
заголовок + бейдж, «что именно соединяется», «как работает аспект», цифры.

## Срезы

## Архитектурные решения (зафиксированы архитектором)

- Источник данных endpoint'а — **кешированный payload дня**
  (`today_payloads_cache` для user+date): там уже есть и `focus.events`,
  и `v2.activationEvidence` со всеми цифрами (orb, exactAt, activeFrom/Until,
  phase, applying, strength, polarity, debug.aspect_angle/max_orb).
  Пересчитывать астрологию НЕ нужно. Cache miss → 404 (UI всегда сначала
  грузит день, значит кеш существует).
- LLM в дрилдауне НЕ участвует — мгновенный ответ, детерминированные тексты.
- Тексты берутся из существующих словарей (не выдумывать новых):
  - функции планет: `PLANET_FUNCTIONS` в `apps/api/app/services/sphere_why_builder.py`;
  - механика аспекта: `ASPECT_MEANINGS` в `apps/api/app/services/synastry_service.py`;
  - формат орба `0°19′`: логика `_format_orb_label` там же (скопировать 5 строк
    в новый builder, приватную функцию кросс-модульно не импортировать);
  - русские имена планет/аспектов: `apps/api/app/services/focus_title_builder.py`.
- Дрилдаун только для СОБЫТИЙ (events). Строки факторов в техническом
  disclosure остаются статичными (out of scope).
- Значение `meaning` (LLM-текст события) берётся из кешированного payload как есть.
