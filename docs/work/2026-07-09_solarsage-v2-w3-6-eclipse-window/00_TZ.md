## Eclipse Calculation

Create a sidecar service:

```text
apps/solarsage/solarsage/services/eclipses.py
```

Follow repository GRACE comment style:
- module header;
- module contract;
- module map;
- function contracts for non-trivial functions;
- no `grace_control` import.

Use Swiss Ephemeris in the sidecar, not API/frontend:
- `swisseph.sol_eclipse_when_glob(target_jd, swe.FLG_SWIEPH, 0, backwards=False|True)`
- `swisseph.lun_eclipse_when(target_jd, swe.FLG_SWIEPH, 0, backwards=False|True)`
- `swisseph.calc_ut(eclipse_jd, swe.SUN|swe.MOON, swe.FLG_SWIEPH)` for zodiac longitude at maximum eclipse.

Candidate logic:
- calculate target JD from request `target_date`, `target_time`, `target_tz`;
- collect nearest previous and next solar eclipse;
- collect nearest previous and next lunar eclipse;
- keep candidates where:
  - future candidate: `0 <= eclipse_jd - target_jd <= days_after`;
  - past candidate: `0 <= target_jd - eclipse_jd <= days_before`;
- choose the nearest candidate by `abs(eclipse_jd - target_jd)`;
- if tied, choose deterministically by `(abs_delta, eclipse_jd, eclipse_kind)`.

Eclipse longitude:
- solar eclipse: use Sun longitude at max eclipse JD;
- lunar eclipse: use Moon longitude at max eclipse JD.

Eclipse type mapping:
- solar: `total`, `annular_total`, `annular`, `partial`;
- lunar: `total`, `partial`, `penumbral`.

Retain raw `retflag` in debug.

## Activation Contract

Activate natal targets within `orb_to_natal` degrees of the chosen eclipse point:
- natal planets;
- natal angles: `ASC`, `DSC`, `MC`, `IC`;
- natal lots from the existing lot helper.

Do not activate houses directly.

Common fields:

```text
technique = eclipse_window
technique_family = eclipse
kind = solar_eclipse_window | lunar_eclipse_window
source_frame = eclipse
target_frame = natal | angle | lot
aspect = conjunction
phase = period
polarity = mixed
```

Stable IDs:

```text
eclipse_window__SOLAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_<PLANET>
eclipse_window__SOLAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_ANGLE_<ANGLE>
eclipse_window__SOLAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_LOT_<LOT>
eclipse_window__LUNAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_<PLANET>
eclipse_window__LUNAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_ANGLE_<ANGLE>
eclipse_window__LUNAR__<TYPE_UPPER>__<YYYY_MM_DD>__CONJUNCTION__NATAL_LOT_<LOT>
```

Use date with underscores, for example `2026_08_12`.

Strength:

```text
orb_factor = max(0, 1 - orb / orb_to_natal)
window_limit = days_after if eclipse_jd >= target_jd else days_before
window_factor = max(0, 1 - abs(days_delta) / window_limit)
strength = round(min(1.0, config_strength * orb_factor * window_factor), 4)
```

If `window_limit <= 0`, fail loudly in tests/dev.

Debug fields must include:
- `eclipse_kind`: `solar | lunar`;
- `eclipse_type`;
- `eclipse_retflag`;
- `eclipse_jd`;
- `eclipse_utc_iso`;
- `eclipse_date`;
- `target_jd`;
- `days_delta`;
- `days_before`;
- `days_after`;
- `eclipse_longitude`;
- `target_longitude`;
- `angular_distance`;
- `orb`;
- `orb_to_natal`;
- `orb_factor`;
- `window_factor`;
- `base_strength`;
- `resolved_house_system`.

Evidence string examples:

```text
Solar total eclipse conjunct natal IC, orb 2.0641°, eclipse 2026-08-12
Solar partial eclipse conjunct lot EROS, orb 1.3017°, eclipse 2026-02-17
```

No broad always-on text like "eclipse season affects everything".

Indexes:
- planet targets -> `by_planet[target_key]`;
- angle targets -> `by_angle[angle]`;
- lot targets -> `by_lot[lot]`;
- no unrelated index writes.
