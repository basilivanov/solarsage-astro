## 3. Current Architecture To Preserve

Current product path:

- `app/(grace)/readings/natal/page.tsx`
- `lib/api/natal.ts`
- `lib/contracts/natal.ts`
- `components/readings/natal-preview/*`
- `components/readings/natal-chart-wheel.tsx`

Required data/API rules:

- `NatalReadingPage` must keep loading data through `fetchNatalPreview()`.
- `fetchNatalPreview()` must keep calling the real endpoint `/api/natal/preview`.
- Render only fields from real `NatalPreviewRead`:
  - `meta`
  - `chart`
  - `highlights`
  - `spheres`
  - `planets`
  - `chapters`
  - `personalHook`
  - `calculationStats`
  - `salesBullets`
  - `fullReportAvailable`
  - `fullReportPriceKopecks`
- Chart UI must use `state.data.chart` only. If chart is `null`, show the existing unavailable state. Do not fabricate planets/houses/aspects.
- Profile-incomplete state must keep using backend `409` mapping from `fetchNatalPreview()`.
- Error retry must keep calling the real `load()` path.
- Full report CTA must remain disabled unless the real product contract explicitly supports fulfillment. In this wave, do not enable payment or route users into paid fulfillment just because mock-preview did.

Do not add a new backend endpoint in this wave.

## 5. In Scope

### 5.1 `/readings/natal` presentation

Bring `/readings/natal` closer to `docs/superpowers/specs/assets/2026-07-07-mock-preview/readings-natal.png`:

- header/back link remains compact and safe-area aware;
- hero card matches oracle hierarchy and mobile first viewport density;
- badges are derived from real `ascSign`, Sun/Moon highlights, and `birthCity`;
- personal hook card is prominent and uses real `personalHook`;
- highlights/planets/spheres/chapters render real preview arrays only;
- natal chart wheel renders real `state.data.chart` only;
- no horizontal overflow on 390px mobile viewport;
- loading, error, profile-incomplete, and ready states remain visually coherent.

### 5.2 Loading, error, profile-incomplete, and ready states

Expose a stable public state contract:

- root `data-testid="natal-preview-screen"`;
- root `data-state="loading|ready|error|profile_incomplete"`;
- root `data-full-report-available="true|false"` when ready;
- loading child `data-testid="natal-preview-loading"` and `role="status"`;
- error child `data-testid="natal-preview-error"` and `role="alert"` with retry button;
- profile-incomplete child `data-testid="natal-profile-incomplete"` and `role="alert"` or `role="status"`;
- ready content child `data-testid="natal-preview-content"`.

Do not silently turn load failure into profile-incomplete or empty state.

### 5.3 UI Semantic/Test Contract

Expose stable selectors and accessibility states:

- `data-testid="natal-preview-header"`;
- `data-testid="natal-preview-back-link"`;
- `data-testid="natal-hero"`;
- `data-testid="natal-hero-badges"`;
- `data-testid="natal-personal-hook"`;
- `data-testid="natal-highlights"`;
- `data-testid="natal-calculation-depth"`;
- existing `data-testid="natal-chart"` must remain on chart;
- existing `data-testid="natal-chart-unavailable"` must remain when chart is absent;
- `data-testid="natal-spheres"`;
- `data-testid="natal-planets"`;
- `data-testid="natal-locked-chapters"`;
- `data-testid="natal-sales-bullets"`;
- `data-testid="natal-full-report-cta"`;
- disabled CTA must use native `disabled` and `aria-disabled="true"`;
- retry buttons must have accessible names.

Tests must not depend on Tailwind class names.
