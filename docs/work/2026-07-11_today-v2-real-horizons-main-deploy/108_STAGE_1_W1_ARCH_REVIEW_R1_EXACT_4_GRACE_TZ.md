## 3. Исправление test GRACE

В `apps/api/tests/test_today_selection_context.py` добавь paired:

~~~text
START_FUNCTION_CONTRACT
END_FUNCTION_CONTRACT
~~~

для каждой функции, которую exact-file GRACE lint классифицирует как public.

Это включает:

1. `_FakeV1Service.score_day`;
2. `_FakeV2Service.score_day`;
3. все pytest functions `test_*`;
4. nested `fail_if_called`;
5. любую другую функцию, которую повторный lint покажет как `GRC010`.

Каждый contract должен иметь все обязательные поля:

~~~text
purpose
inputs
returns
side_effects
emitted_logs
error_behavior
~~~

Требования к содержанию:

- описывать реальную проверку, а не копировать одно общее предложение;
- `inputs` перечисляет pytest fixtures/parameters или `none`;
- `returns: none` для тестов;
- `side_effects` честно указывает monkeypatch, bounded threads или `none`;
- `emitted_logs: none`;
- `error_behavior` указывает assertion failure / expected exception semantics;
- идентификаторы должны быть стабильными и уникальными в пределах файла;
- contracts ставить внутри тела функции в формате, который понимает
  `scripts/grace_lint.py`;
- не добавлять `# noqa`, lint suppression, generated bypass или исключение пути.

Не менять assertions, parametrization, barrier, fake behavior, imports или
количество test cases, кроме минимальной форматной необходимости.
