## 4. Механизм: почему «сошлось» неизбежно (исправлено)

1. **Луна даёт якорь ежедневно — и мажорный.** Из 1232 якорей 935 лунные:
   467 мажорных + 468 минорных. В каждом из 81 дня есть ≥1 мажорный аспект
   Луны. Поэтому фильтр «только мажорные» не отсекает ничего.
   *(В v1 ошибочно: «76% минорные» и «5/81 дней только с минорными»; верно:
   минорных половина; 5 дней — только с лунными якорями, но с мажорными
   среди них: 06-03, 07-15, 07-19, 07-25, 07-26.)*
2. `classify_temporal_role` считает любой `exact_at` внутри локального дня
   полноценным якорем — без веса планеты, аспекта и орба.
3. **Широкий факторный универсум:** 9 типов аспектов, орбисы до 8°, цели —
   планеты, углы и лоты (`grace/canon/aspect_rules.v1.yml`,
   `apps/solarsage/solarsage/services/activation_builder.py:649`). Почти любой
   якорь находит активный фактор на том же target.
4. **Фон — не главный виновник:** без фоновых связок convergence остаётся
   100% (медиана ~120 supporting против ~30 background). Связки образуются
   внутри «сегодняшних» и долгих транзитов сами по себе.
5. canonical_event устраняет технические дубли, но НЕ делает свидетельства
   независимыми: «Луна квадрат Сатурн» и «Марс квадрат Сатурн» — два факта,
   но один драйвер-тема.

Вывод: проблема не «чем заполнить пустые дни», а **как не считать любой
астрологический шум независимым подтверждением**. Селективность нельзя
получить из eligibility — нужна фильтрация значимости ДО evidence.

## 5. Следствия (нормативы — master v1.3, §4.3)

1. Разделение: `raw fact → публично значимый импульс → независимая
   evidence-единица → convergence → presentation`.
2. ~150 сырых параметров не удаляются (нужны аудиту и replay), но в
   продуктовую evidence-модель попадают немногие проверенные независимые.
3. Лунный аспект, даже мажорный, по умолчанию — импульс со временем, не hero
   (явные исключения — structural lunar event classes: eclipse/lunation).
4. Supporting-фактор проходит собственный порог значимости; слабый аспект
   на краю орбиса — не подтверждение. Фон — только контекст.
5. «Сошлось» = ≥2 действительно независимых горизонта/драйвера, минимум один
   редкий или структурно значимый. Одно исключительное событие — «Главное
   событие дня», не схождение.
6. Отдельного «пустого» состояния нет: аспекты есть практически всегда.
   Публичный контракт — `convergence_today | quiet_day | unavailable`;
   quiet_day с 0 импульсов показывает только нейтральный детерминированный
   контекст, текст не выдумывается.
7. Обычный день — 0–3 отранжированных импульса, не хронологическая портянка.

## 6. Оговорки

- Один субъект, одно окно (июнь–август 2026); лунный механизм универсален,
  количество групп у других карт отличается.
- Probe использует старую широкую проекцию сфер и старый факторный универсум:
  0/81 no_signal НЕ переносится автоматически на новую модель после честной
  фильтрации — распределение состояний будет пересчитано в W4.
- Не моделировались evidence-коэффициенты, ranking, data_quality.
- Группировка в пробе — connected components: размеры групп завышены, на
  состояние дня не влияет.
